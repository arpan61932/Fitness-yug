FITNESS YUG

DEMO:- https://fitnessyug.vercel.app/

**Fitness Yug** is a modern full-stack gym website built using React, Tailwind CSS, Node.js, Express.js, and SQLite. It allows users to explore fitness programs, membership plans, and submit membership requests.

## Features

- Modern gym landing page
- Fitness programs including Hypertrophy, HIIT, and Powerlifting
- Multiple membership plans
- Membership registration form
- Member data stored in SQLite database
- Admin login system
- Admin dashboard to manage registered members
- Delete member records
- Responsive design
- Smooth scroll and reveal animations

## Tech Stack
**Frontend:** React, Tailwind CSS, Vite  
**Backend:** Node.js, Express.js  
**Database:** SQLite  

**Deployment:** Vercel
